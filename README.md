# Shorts Studio — สร้างเรื่องสั้นบนหน้าเว็บ

## ดาวน์โหลดไปเปิดบน Windows

[ดาวน์โหลด ShortsStudio.zip](https://github.com/Tikkie-hub/stick-figure-shorts/raw/refs/heads/shorts-studio/downloads/ShortsStudio.zip)

แตก ZIP แล้วเปิด `ShortsStudio/web/start.bat` ต้องมี Python 3.10–3.12 (แนะนำ 3.12)และ
อินเทอร์เน็ต โปรแกรมจะติดตั้ง dependencies และเปิดเว็บที่พอร์ต 5000
ไฟล์ ZIP รวมซอร์สและบทตัวอย่าง ไม่รวม API Key, วิดีโอที่เรนเดอร์ หรือ venv

หน้าเว็บหลักให้เลือกเรื่องตั้งต้น แก้บท เลือกท่าทางตัวละครและโทนสี แล้วสร้าง
MP4 9:16 พร้อมเสียงไทยและซับสั้นตามคำพูด โดยไม่ต้องแก้โค้ดหรือมี Gemini Key

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r web/requirements.txt
python web/app.py
```

เปิดหน้าเว็บผ่านพอร์ต 5000 ของเครื่องที่รันแอป บน Windows ดับเบิลคลิก
`web/start.bat` เพื่อติดตั้งใน venv และเริ่มเว็บ โดยไม่ต้องแก้พาธในสคริปต์
ต้องมี FFmpeg/ffprobe สำหรับตรวจไฟล์อัปโหลด และการทดสอบ

1. เลือกเรื่องสั้นชวนสงสัย เรื่องสร้างแรงใจ หรือเรื่องความรู้
2. แก้หัวข้อและบทพากย์ของแต่ละฉาก (สูงสุด 6 ฉาก / 1,200 ตัวอักษร)
3. เลือกแอ็กชัน เช่น เปิดกล่อง อ่านจดหมาย วิ่ง คิด ดีใจ หรืออวกาศ
4. เลือกโทนสี หรืออัปโหลดวิดีโอ/GIF เป็นพื้นหลัง (ไม่เกิน 80 MB / 5 นาที)
5. กดสร้างคลิป รอแถบความคืบหน้า แล้วเปิดเสียงดูตัวอย่างหรือดาวน์โหลด MP4

ซับใช้ **WordBoundary ของ Edge TTS** จริง แสดงวลีสั้นไม่เกิน 3 คำ
และไฮไลต์คำที่กำลังพูด ไม่ใช้การหารเวลาตามจำนวนตัวอักษร ตัวละครและพร็อพ
เคลื่อนไหวตามแอ็กชัน พร้อมพาร์ติเคิล การขยับช็อต และกล่องซับเด้ง
คงช่วงเงียบท้ายฉาก 0.3 วินาที ผลลัพธ์ 1080×1920, 30 fps
การ์ตูนสร้างด้วยโค้ด ไม่ได้ใช้โมเดลสร้างวิดีโอหรือภาพตามพรอมป์ต์
เรื่องตั้งต้นเป็นแม่แบบที่เขียนไว้ ไม่ใช่ AI แต่งเรื่องใหม่จากหัวข้ออิสระ

บทที่แก้บันทึกในเบราว์เซอร์อัตโนมัติ งานและคลิปอยู่ใน
`outputs/studio/<job-id>/` พร้อม `project.json`, `timeline.json` และเสียงแต่ละฉาก
กดดูคลิปที่สร้างไว้ได้บนหน้าเว็บ ไม่ต้องเปลี่ยนโค้ดเมื่อเปลี่ยนเรื่อง
พื้นหลัง GIF/วิดีโอถูกครอปกึ่งกลางและวน โดยปิดเสียงเดิม
แอปนี้เป็นสตูดิโอพัฒนาแบบผู้ใช้เดียว ประมวลผลครั้งละหนึ่งงาน
ถ้าเว็บเริ่มใหม่ระหว่างงาน ให้กดสร้างใหม่; ไฟล์ที่สร้างสำเร็จยังอยู่
การเปิดเซิร์ฟเวอร์พัฒนาไม่ได้สร้างลิงก์เว็บไซต์สาธารณะให้อัตโนมัติ

ไฟล์หลัก: `web/templates/studio.html` (หน้าเว็บ), `web/studio.py` (งานและอัปโหลด),
`studio_render.py` (เรนเดอร์และจับเวลาคำ) เครื่องมือ Gemini เดิมย้ายไป `/gemini`
CLI `auto_knowledge_shorts.py` ด้านล่างยังคงรูปแบบเดิมเพื่อใช้งานย้อนหลัง

ทดสอบ: `python -m unittest discover -s tests -v`

# 🐟 Stick Figure Shorts Studio (ก้างปลา เปลี่ยนชีวิต)

ระบบผลิตคอนเทนต์คลิปสั้นอนิเมชั่นก้างปลาไวรัล (TikTok / YouTube Shorts / Reels) ความยาว ~45 วินาที พร้อมคลัง Prompt และเครื่องมือช่วยสร้างภาพด้วย Gemini AI

---

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```
stick-figure-shorts/
├── CODEX.md                # 🤖 คู่มือคำสั่งและ System Prompt สำหรับ Codex / AI
├── README.md               # 📖 เอกสารภาพรวมโปรเจกต์
├── scripts/                # 📝 สคริปต์บทพูดและคำพากย์แยกตาม EP
│   └── ep1_waking_up.md    # EP.1 "ตื่นเช้าไม่ได้ ไม่ใช่เพราะขี้เกียจ"
├── prompts/                # 🎨 คลัง Prompt แต่ละฉากพร้อมการล็อกสไตล์
│   └── ep1_prompts.md      # ชุด Prompt ทุกช็อตของ EP.1
├── assets/                 # 🖼️ ไฟล์รูปภาพที่สร้างแล้ว
│   └── ep1/                # ช็อตทั้งหมดของ EP.1 ขนาด 9:16
└── web/                    # 🌐 เว็บแอป Gemini Studio (Flask + Gemini API)
    ├── app.py
    ├── requirements.txt
    ├── templates/
    └── start.bat
```

## 🎯 กฎเหล็กของตัวละครและสไตล์ภาพ (Character Bible)

1. **ตัวละคร (Character):**
   - ตัวการ์ตูนก้างปลา 2D (Stick Figure) สไตล์ Doodle มินิมอล
   - หัวกลมสีเหลืองสดใส (Solid Bright Yellow Head)
   - แขนขาเป็นเส้นก้างปลาสีดำธรรมดา (Simple Black Stick Limbs)
   - เส้นขอบหมึกดำหนา คมชัด (Bold Crisp Black Ink Outlines)
2. **โทนสีและแสงเงา (Color Palette & Lighting):**
   - ห้องนอน/ฉากโทนสีน้ำเงินเข้มยามค่ำคืน (Dark Navy Blue Atmosphere)
   - ตัดกับแสงไฟโคมไฟข้างเตียงสีส้มอุ่น (Warm Bedside Lamp Glow)
   - สไตล์การลงสีแบบ Graphic Novel / Comic Cel-Shading
3. **สัดส่วนภาพ (Aspect Ratio):**
   - แนวตั้ง **9:16** สำหรับ TikTok โดยเฉพาะ
4. **ข้อห้ามเด็ดขาด (Negative Constraints):**
   - ห้ามมีตัวหนังสือหรือตัวเลขลอย (NO text, NO artificial floating numbers)
   - ห้ามมีไอคอน AI แปลกปลอม (ให้ใช้วัตถุจริงหรือท่าทางตัวการ์ตูนแทน)

## 🎬 สูตรการตัดต่อ 45 วินาที (CapCut / Premiere Pro)

- **0:00 - 0:08 (Hook):** เปิดตัวปัญหา + ตั้งนาฬิกาปลุกหลายเรือน
- **0:08 - 0:15 (Pain Point):** เลื่อนปลุก (Snooze) 5 นาทีกลายเป็น 2 ชั่วโมง
- **0:15 - 0:22 (Method 1):** วางมือถือไว้อีกห้อง ลุกเดินไปปิด = ตื่นอัตโนมัติ
- **0:22 - 0:30 (Method 2):** กฎ 5 วินาที นับ 5-4-3-2-1 ดีดตัวลุกทันที
- **0:30 - 0:37 (Method 3):** ตั้งเป้าหมายเล็กที่สุด ดื่มน้ำ 1 แก้ว
- **0:37 - 0:42 (Twist):** หยุดคิดทวิสต์ "ถ้าไม่มีเป้าหมายในชีวิต วิธีไหนก็ไม่ช่วย"
- **0:42 - 0:45 (CTA):** ชวนกดเซฟและกดติดตามรอ EP.2

## Universal Knowledge Shorts Factory

สร้างวิดีโอให้ความรู้ภาษาไทยแนวตั้ง **1080×1920, 30 fps** ด้วยเสียง
`th-TH-NiwatNeural` จาก Edge TTS และคลิปพื้นหลังจาก Pixabay หรือคลิปในเครื่อง ไม่ใช้ Gemini

```text
auto_knowledge_shorts.py   # CLI และขั้นตอนสร้างวิดีโอ
requirements.txt          # dependencies ของระบบวิดีโอ (MoviePy 2)
topics/
  space.json              # อวกาศและจักรวาล
  brain.json              # สมองและจิตวิทยา
  history.json            # ประวัติศาสตร์
assets/fonts/             # Kanit-Bold.ttf ดาวน์โหลดเมื่อใช้งานครั้งแรก
outputs/                  # MP4 และ .credits.json แหล่งที่มาคลิป
```

### ติดตั้งและใช้งาน

ใช้ Python 3.10–3.12 (แนะนำ 3.12) พร้อม FFmpeg (ต้องมีตัวเข้ารหัส libx264 และ AAC)
แนะนำ Python 3.12 และ Pillow wheel ที่รองรับ RAQM สำหรับสระและวรรณยุกต์ไทย

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
# ไม่ต้องมีคีย์: ใช้คลิปตัวอย่างใน assets/backgrounds/ อัตโนมัติ
# หากต้องการค้นหาคลิปตามหัวข้อ ตั้ง PIXABAY_API_KEY ผ่าน environment
python auto_knowledge_shorts.py --topic space
python auto_knowledge_shorts.py --topic brain --output outputs/brain.mp4
python auto_knowledge_shorts.py --topic history
```

บน Windows ใช้ `.venv\Scripts\activate` เพื่อเปิด virtual environment
รับคีย์ Pixabay ได้จาก https://pixabay.com/api/docs/ และอย่า commit คีย์ลง Git
Edge TTS ไม่ต้องใช้ API Key แต่ต้องเชื่อมต่อบริการออนไลน์ได้
ต้องอนุญาต `pixabay.com`, โฮสต์ไฟล์วิดีโอที่ Pixabay ส่งกลับ,
`raw.githubusercontent.com` สำหรับฟอนต์ และบริการ Microsoft Edge TTS
เช่น `speech.platform.bing.com` (รวม WebSocket) ตามเครือข่ายที่ใช้งาน

แต่ละไฟล์หัวข้อเป็น JSON array โดยแต่ละฉากมีสตริงที่ไม่ว่างสี่ช่อง:

```json
[
  {
    "header_title": "อวกาศและจักรวาล",
    "highlight_text": "มองไกล คือมองอดีต",
    "narration": "แสงต้องใช้เวลาเดินทาง ภาพดาวที่เราเห็นจึงเป็นภาพจากอดีต",
    "search_keyword": "stars galaxy"
  }
]
```

เพิ่มหมวดได้ด้วยการสร้าง `topics/<ชื่อ>.json` แล้วใช้ `--topic <ชื่อ>`
ตรวจสอบข้อเท็จจริงก่อนเผยแพร่ เนื้อหาตัวอย่างเป็นจุดเริ่มต้นสำหรับการผลิต
คลิปพื้นหลังถูกตัดเสียง ครอปตรงกลาง และเล่นวนหากสั้นกว่าเสียงพากย์
ความยาวฉากเท่ากับเสียงพากย์จริงบวกช่วงเงียบ 0.3 วินาที ซับแบ่งตามความกว้างและแสดงตามสัดส่วน
ความยาวข้อความ ไม่ใช่เวลารายคำ ฟอนต์จะย่อให้พอดีกับการ์ด; ข้อความที่ยาว
เกินไปจะทำให้คำสั่งหยุดพร้อมข้อผิดพลาด ให้แบ่งเป็นฉากที่สั้นลง
ใช้ `--font /path/to/font.ttf` หากมีฟอนต์ไทยในเครื่องอยู่แล้ว

ระบบเก็บไฟล์ชั่วคราวแยกและลบหลังจบงาน บันทึกแหล่งที่มาของ Pixabay ใน
`outputs/<ชื่อ>.credits.json` ควบคู่กับ MP4 ตรวจสอบเงื่อนไขการใช้งาน Pixabay
และสิทธิ์ของเนื้อหาก่อนเผยแพร่ การเรนเดอร์ทับไฟล์ output เดิมได้
ระบบวิดีโอใช้ MoviePy 2; `create_story_video.py` เดิมใช้ API ของ MoviePy 1
จึงควรแยก virtual environment หากยังต้องใช้สคริปต์เดิม

ทดสอบด้วย `python -m unittest discover -s tests -v` ชุดทดสอบใช้เสียงและ
คลิปจำลองแทนบริการออนไลน์ แต่เรนเดอร์ MP4 จริงและตรวจด้วย ffprobe
ต้องมีฟอนต์ `/usr/share/fonts/truetype/noto/NotoSansThai-Bold.ttf` และ FFmpeg
สำหรับการทดสอบเรนเดอร์ มิฉะนั้นการทดสอบส่วนนั้นจะถูกข้าม


### พื้นหลังเมื่อไม่มีคีย์ Pixabay

หากไม่ตั้ง `PIXABAY_API_KEY` ระบบสุ่มคลิปจาก `assets/backgrounds/`
ถ้าโฟลเดอร์ว่างจะดาวน์โหลดตัวอย่าง Big Buck Bunny (CC BY 3.0) อัตโนมัติ
ดูเครดิตและเงื่อนไขใน `assets/backgrounds/README.md` พื้นหลังตัวอย่างไม่ได้
ตรงกับเนื้อหาหัวข้อ เลือกโฟลเดอร์อื่นได้ด้วย `--backgrounds /path/to/clips`
เมื่อใช้ Pixabay ระบบค้นหาตาม `search_keyword`; คีย์ผิดหรือการค้นหาล้มเหลว
จะรายงานข้อผิดพลาดแทนการเปลี่ยนไปใช้คลิปอื่นเงียบ ๆ
เสียงแต่ละฉากเป็น Edge TTS จริง ตามด้วยช่วงเงียบ 0.3 วินาที
ต้องอนุญาต `speech.platform.bing.com` ผ่าน HTTPS/WebSocket จึงจะสร้างเสียงได้
การบันทึกเครือข่ายในฉบับร่างยังไม่ทำให้เครื่องที่กำลังรันเข้าถึงบริการได้ทันที

CLI ใช้ `truststore` เพื่ออ่านใบรับรองที่ระบบเชื่อถือ รวมถึง CA ของพร็อกซี
องค์กร โดยยังตรวจสอบ TLS ตามปกติ และใช้ `HTTPS_PROXY` หากตั้งไว้

## โหมดเรื่องเล่า 2D และการร่างจากไอเดีย

หน้าเว็บมีช่องไอเดีย แนวเรื่อง และตอนจบ ปุ่ม “ร่างเรื่องและออกแบบฉาก” จะสร้าง
storyboard ที่แก้ต่อได้สูงสุด 6 ฉาก แต่ละฉากเลือกห้องพัก ทางเดิน ลิฟต์ เมือง
หรือกระดานอธิบายได้ พร้อมภาพกว้าง/กลาง/ใกล้/รายละเอียด ตัวละครหนึ่งหรือสองคน
สีหน้า โทรศัพท์ ขวดน้ำ จดหมาย กล่อง และแอ็กชันเคาะประตู ฟัง เปิดประตู ยื่นของ
เดิน และวิ่ง กราฟิกมีวงแสง ผังอาคาร นับถอยหลัง และเปรียบเทียบสองทาง
เปลี่ยนชื่อตัวละครแล้วระบบแทนชื่อเดิมในบทให้ ตัวละครและภาพทั้งหมดสร้างขึ้นใหม่
ด้วย renderer ของโปรเจกต์ ไม่ดึงตัวละครหรือภาพจากคลิปตัวอย่างมาใช้

- **ร่างจากโครงเรื่อง:** ใช้งานได้ทันที ไม่มีคีย์ เป็นการประกอบ plot beats ที่
  รองรับตามแนวเรื่อง สถานที่ และสิ่งของที่ตรวจพบในไอเดีย ไม่ใช่ AI แต่งอิสระ
  ไอเดียที่นอกคลังต้องแก้บทเอง โหมดความรู้ร่างแนวทางตั้งคำถาม/ตรวจหลักฐาน
  ไม่สร้างข้อเท็จจริงเฉพาะเรื่องที่ยังไม่ได้ตรวจสอบ
- **AI แต่งจากไอเดีย:** เชื่อมต่อ Gemini โดยตั้ง `STORY_API_KEY` เป็น secret
  ใน environment ของเซิร์ฟเวอร์ครั้งเดียว (หรือใช้ `GEMINI_API_KEY`/
  `GOOGLE_API_KEY` ที่มีอยู่) ไม่ใส่คีย์ในบทหรือแชต และไม่เก็บคีย์ในไฟล์งาน
  โมเดลเริ่มต้น `gemini-2.5-flash`; เปลี่ยนด้วย `STORY_GEMINI_MODEL`
  โหมดนี้ต้องมีเครือข่ายถึง `generativelanguage.googleapis.com` และโควตาที่ใช้ได้
  ผลลัพธ์ผ่านการตรวจ schema ก่อนนำมาแก้ไขหรือเรนเดอร์ ถ้าบริการล้มเหลวจะรายงาน
  ข้อผิดพลาด ไม่แอบเปลี่ยนเป็นบทจากแม่แบบ การตั้งค่าปัจจุบันยังไม่มีคีย์ จึงยัง
  ไม่ได้ยืนยันการแต่งเรื่องผ่านโมเดลจริง

เลือก “เรื่องเล่า 2D” เพื่อใช้ฉากและตัวละครชุดใหม่ หรือ “ก้างปลาแบบเดิม” เพื่อ
ใช้ renderer เดิม ซับเลือกกลาง/ล่างได้ ทั้งสองแบบใช้เวลาคำจริงจาก Edge TTS
ภาพแบบใหม่รองรับรูปแบบที่กำหนดไว้ ไม่ใช่ระบบสร้างภาพ/แอ็กชันทุกแบบจากข้อความ
การแต่งด้วย AI ต้องตรวจความต่อเนื่องและข้อเท็จจริงก่อนเผยแพร่

ไฟล์ใหม่: `story_schema.py` (คำศัพท์ที่รองรับ), `story_planner.py` (ร่างเรื่อง),
`story_art.py` (ฉากและตัวละคร) ส่วนเสียงและประกอบวิดีโอยังอยู่ `studio_render.py`
API ใหม่: `GET /api/studio/capabilities`, `POST /api/studio/draft`

ปุ่ม “ดูภาพฉากก่อนสร้าง” ในรายละเอียดแต่ละฉากเรียก
`POST /api/studio/preview` เพื่อดูภาพนิ่งตามการตั้งค่าจริงก่อนเรนเดอร์ทั้งเรื่อง
คลิปตัวอย่าง cinematic ของการทดสอบอยู่ที่ `outputs/cinematic-story-demo.mp4`
(6 ฉาก ประมาณ 29 วินาที) พร้อมภาพรวม `outputs/cinematic-story-preview.jpg`
และภาพหน้าเว็บ `outputs/cinematic-studio-web.png`

ดาวน์โหลดไฟล์ติดตั้งจากปุ่ม “ดาวน์โหลดโปรเจกต์ ZIP” บนหัวหน้าเว็บได้โดยตรง
ถ้าลิงก์ Artifact ในแชตดาวน์โหลดไม่ได้ ปุ่มนี้ส่ง ZIP ผ่านเว็บโดยไม่ใช้ Artifact

Windows launcher แสดงขั้นตอน [1/4]–[4/4] และใช้ Python launcher ก่อน PATH
รองรับ Python 3.10–3.12 ตาม dependencies ที่ตรึงไว้ หากแถบชื่อหน้าต่างขึ้น Select
ให้กด Esc เพื่อออกจากโหมดเลือกข้อความ เบราว์เซอร์จะเปิดหลังเซิร์ฟเวอร์พร้อมแล้ว


### ฟอนต์ไทยและการตรวจข้อผิดพลาดบน Windows

หาก Pillow ไม่มี RAQM ระบบใช้ HarfBuzz + FreeType เพื่อจัดรูปอักษรไทยและ
วางสระ/วรรณยุกต์อย่างถูกต้อง ไม่ถอยไปใช้การวาดตัวอักษรแบบ BASIC
ไลบรารีติดตั้งผ่าน requirements โดยอัตโนมัติเมื่อเปิด start.bat
ข้อผิดพลาดจะแสดงรหัสและขั้นตอน เช่น THAI_FONT_SETUP, FONT_LOAD_FAILED,
TTS_FAILED หรือ TTS_TIMING_MISSING และบันทึก error.json/render.log ในงานนั้น
บันทึกแสดงตำแหน่งโค้ดและข้อความที่กรอง URL/ข้อมูลรับรองแล้ว ไม่แสดงค่า secret
RuntimeError จากเวอร์ชันเก่าเพียงคำเดียวไม่สามารถยืนยันสาเหตุที่แท้จริงได้
