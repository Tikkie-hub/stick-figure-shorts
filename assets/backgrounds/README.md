# Local fallback backgrounds

Place .mp4, .mov or .webm clips you have permission to use here. With no
PIXABAY_API_KEY the renderer chooses a random clip per scene. If none exist,
it downloads big_buck_bunny.mp4 from:
https://raw.githubusercontent.com/mediaelement/mediaelement-files/master/big_buck_bunny.mp4

Sample source: Big Buck Bunny, © 2008 Blender Foundation / www.bigbuckbunny.org.

Credit Blender Foundation when publishing a video containing this sample.
This is a generic motion sample, not footage specifically illustrating the topic.
The sample is cached locally and omitted from Git; it can be downloaded again.
This sample is 640x360 and will be cropped and upscaled. For sharper results,
replace it with your own high-resolution footage (preferably 1080x1920).
